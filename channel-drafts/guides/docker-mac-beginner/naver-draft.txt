Docker가 뭔지도 몰라도 Mac에 안전하게 설치하는 법

Apple Silicon과 Intel 확인부터 설치 완료 검사까지 초보자 화면 기준으로 정리합니다.

따라 하는 순서
1. Apple 메뉴 → 이 Mac에 관하여에서 칩 종류 확인
2. 공식 페이지에서 Apple Silicon 또는 Intel 설치 파일 선택
3. Docker.dmg를 열고 Docker를 응용 프로그램으로 이동
4. Docker를 실행하고 약관·권한 화면을 직접 확인
5. 터미널에서 docker version과 docker ps 확인

완료 전 확인
• 공식 Docker 사이트에서 받았는가
• 지원되는 macOS와 4GB 이상 RAM 조건을 확인했는가
• 회사 사용이라면 Docker Desktop 라이선스를 확인했는가
