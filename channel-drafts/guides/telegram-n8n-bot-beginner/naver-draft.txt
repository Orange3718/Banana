Telegram Bot을 n8n의 원격 리모컨으로 연결하는 법

BotFather 생성부터 테스트 메시지, Chat ID, n8n 자격증명까지 안전하게 연결합니다.

따라 하는 순서
1. BotFather에서 새 Bot 생성
2. 토큰은 복사 후 비밀 저장소에만 보관
3. Bot과 개인 채팅을 열고 start 전송
4. n8n Telegram credential에 토큰 입력
5. 테스트 workflow로 수신·응답 확인
6. 실패·승인·보고 메시지를 분리

완료 전 확인
• Bot 토큰을 캡처나 Git에 남기지 않았는가
• 허용된 Chat ID만 처리하는가
• 비용·외부공개 승인은 명시적으로 분리했는가
