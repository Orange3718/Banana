# 외부 채널 게시 대기본

## 안전한 운영 원칙

- 자체 사이트가 원본이다.
- Blogger·Tistory·Naver에는 원문을 그대로 복사하지 않고 플랫폼별 도입부와 사례를 바꾼다.
- 외부 글 안에서 핵심 답을 제공하고, 개인 조건 계산만 자체 Tool로 연결한다.
- 제휴 링크가 있으면 글 첫 화면과 링크 근처에 경제적 이해관계를 표시한다.
- 직접 사용하지 않은 제품은 `후기`, `써보니`, `리뷰`라고 쓰지 않는다.

## Blogger

Blogger API v3는 공식적으로 글 초안 생성을 지원한다. Google OAuth와 Blog ID를 n8n에 연결한 뒤 `isDraft=true`로만 생성하고, Owner 승인 후 공개한다.

공식 문서: https://developers.google.com/blogger/docs/3.0/reference/posts/insert

## Tistory

공식 Open API가 종료되어 비공식 내부 API·쿠키 자동화는 사용하지 않는다. 아래 순서로 운영한다.

1. n8n이 플랫폼용 HTML 초안을 생성한다.
2. Telegram으로 제목·요약·원문 URL을 보낸다.
3. Owner가 Tistory 글쓰기 화면의 HTML 모드에 붙여 넣는다.
4. 미리보기에서 표·링크·광고 고지를 확인하고 공개한다.

## Naver Blog

검색 답변을 글 안에 남기고 계산기만 자체 사이트로 연결한다. 자동 로그인·클릭 게시 대신 초안 생성 후 수동 공개한다.
