# LED 마스크 쇼츠 초안 — 로컬 Qwen 3.5 4B 생성

## 상태

아이디어 초안. 게시 전 판매 페이지와 제조사 설명으로 안전성·인증 표현을 확인해야 한다.

## 구성

- 훅: LED 마스크는 피부에 직접 닿는 기기이므로, 무조건 사기 전에 꼭 확인하세요.
- 장면 1: 사용시간과 눈 보호 안내가 제품 설명에 있는지 확인
- 장면 2: 무게·착용감·유선/무선 방식을 비교
- 장면 3: A/S·반품·구성품을 판매 페이지에서 확인
- CTA: LED 마스크 구매 체크리스트에서 여섯 항목을 먼저 비교하세요.

## 운영 원칙

영상은 로컬 모델로 대본만 만들고, 의료 효능·인증·성능은 자동 확정하지 않는다. 실제 공개는 페이지의 체크리스트를 중심으로 하고, 영상은 보조 유입 채널로 사용한다.
