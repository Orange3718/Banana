GitHub 비밀번호 없이 SSH로 clone·pull·push하고 Pages까지 공개하기

SSH 키의 공개키와 개인키 차이, 연결 확인, 안전한 정적 사이트 배포를 한 번에 정리합니다.

이 글의 목표
명령어를 외우는 것이 아니라 무엇을 왜 설치하고, 어디까지 성공하면 다음 단계로 가는지 이해하는 것입니다.
보안 원칙
비밀번호·API 키·2FA 코드·SSH 개인키는 블로그, GitHub, 채팅에 입력하지 않습니다. 화면에는 가려진 예시만 사용합니다.

따라 하는 순서

기존 SSH 키 확인
기기별 새 Ed25519 키 생성
개인키는 Mac에 두고 공개키만 GitHub에 등록
ssh -T로 GitHub 연결 검사
SSH 주소로 저장소 clone
pull·commit·push 후 Pages 배포 확인

완료 전에 확인하세요

  • 개인키 파일 내용을 GitHub나 채팅에 붙이지 않았는가
  • 2FA 코드는 GitHub 화면에만 입력했는가
  • push 전 git status로 비밀 파일을 확인했는가

막히면 이렇게 확인하세요

한 번에 여러 설정을 바꾸지 말고, 현재 단계의 앱이 실행 중인지와 오류 문구를 먼저 확인합니다. 오류 화면을 공유할 때는 이메일·IP·토큰·키를 가립니다.
