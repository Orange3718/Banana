실제로 구축하고 검증한 입문 가이드

Docker compose.yml에 비밀번호를 쓰면 안 되는 이유

환경변수·secret 파일·Git 제외 규칙을 초보자 관점에서 구분합니다.

입문약 20분
이 글의 목표
명령어를 외우는 것이 아니라 무엇을 왜 설치하고, 어디까지 성공하면 다음 단계로 가는지 이해하는 것입니다.
보안 원칙
비밀번호·API 키·2FA 코드·SSH 개인키는 블로그, GitHub, 채팅에 입력하지 않습니다. 화면에는 가려진 예시만 사용합니다.

따라 하는 순서

공개 설정과 비밀값 목록 분리
예시용 .env.example 작성
실제 .env는 .gitignore에 추가
서비스가 환경변수에서 값을 읽도록 구성
로그와 오류 화면에서 비밀값 노출 확인
유출 의심 시 즉시 폐기·재발급

완료 전에 확인하세요

  • git status에 .env가 나타나지 않는가
  • compose 파일에 토큰·비밀번호가 없는가
  • 메신저로 비밀값을 전달하지 않았는가

막히면 이렇게 확인하세요

한 번에 여러 설정을 바꾸지 말고, 현재 단계의 앱이 실행 중인지와 오류 문구를 먼저 확인합니다. 오류 화면을 공유할 때는 이메일·IP·토큰·키를 가립니다.
