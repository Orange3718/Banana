Telegram Bot을 n8n의 원격 리모컨으로 연결하는 법

BotFather 생성부터 테스트 메시지, Chat ID, n8n 자격증명까지 안전하게 연결합니다.

입문약 25분
이 글의 목표
명령어를 외우는 것이 아니라 무엇을 왜 설치하고, 어디까지 성공하면 다음 단계로 가는지 이해하는 것입니다.
보안 원칙
비밀번호·API 키·2FA 코드·SSH 개인키는 블로그, GitHub, 채팅에 입력하지 않습니다. 화면에는 가려진 예시만 사용합니다.

따라 하는 순서

BotFather에서 새 Bot 생성
토큰은 복사 후 비밀 저장소에만 보관
Bot과 개인 채팅을 열고 start 전송
n8n Telegram credential에 토큰 입력
테스트 workflow로 수신·응답 확인
실패·승인·보고 메시지를 분리

완료 전에 확인하세요

  • Bot 토큰을 캡처나 Git에 남기지 않았는가
  • 허용된 Chat ID만 처리하는가
  • 비용·외부공개 승인은 명시적으로 분리했는가

막히면 이렇게 확인하세요

한 번에 여러 설정을 바꾸지 말고, 현재 단계의 앱이 실행 중인지와 오류 문구를 먼저 확인합니다. 오류 화면을 공유할 때는 이메일·IP·토큰·키를 가립니다.
