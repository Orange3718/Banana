Docker가 뭔지도 몰라도 Mac에 안전하게 설치하는 법

Apple Silicon과 Intel 확인부터 설치 완료 검사까지 초보자 화면 기준으로 정리합니다.

입문약 15분
이 글의 목표
명령어를 외우는 것이 아니라 무엇을 왜 설치하고, 어디까지 성공하면 다음 단계로 가는지 이해하는 것입니다.
보안 원칙
비밀번호·API 키·2FA 코드·SSH 개인키는 블로그, GitHub, 채팅에 입력하지 않습니다. 화면에는 가려진 예시만 사용합니다.

따라 하는 순서

Apple 메뉴 → 이 Mac에 관하여에서 칩 종류 확인
공식 페이지에서 Apple Silicon 또는 Intel 설치 파일 선택
Docker.dmg를 열고 Docker를 응용 프로그램으로 이동
Docker를 실행하고 약관·권한 화면을 직접 확인
터미널에서 docker version과 docker ps 확인

완료 전에 확인하세요

  • 공식 Docker 사이트에서 받았는가
  • 지원되는 macOS와 4GB 이상 RAM 조건을 확인했는가
  • 회사 사용이라면 Docker Desktop 라이선스를 확인했는가

막히면 이렇게 확인하세요

한 번에 여러 설정을 바꾸지 말고, 현재 단계의 앱이 실행 중인지와 오류 문구를 먼저 확인합니다. 오류 화면을 공유할 때는 이메일·IP·토큰·키를 가립니다.
