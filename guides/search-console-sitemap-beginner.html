보안 원칙
비밀번호·API 키·2FA 코드·SSH 개인키는 블로그, GitHub, 채팅에 입력하지 않습니다. 화면에는 가려진 예시만 사용합니다.

따라 하는 순서

공개 URL과 HTTPS 접속 확인
robots.txt와 sitemap.xml 열기
Search Console 속성 추가
DNS 또는 HTML 태그로 소유권 확인
sitemap URL 제출
페이지 색인과 오류를 주기적으로 확인

완료 전에 확인하세요

  • 비공개·미완성 페이지를 sitemap에 넣지 않았는가
  • canonical 주소가 실제 공개 주소와 같은가
  • 색인 요청을 반복 제출로 오해하지 않았는가

막히면 이렇게 확인하세요

한 번에 여러 설정을 바꾸지 말고, 현재 단계의 앱이 실행 중인지와 오류 문구를 먼저 확인합니다. 오류 화면을 공유할 때는 이메일·IP·토큰·키를 가립니다.
