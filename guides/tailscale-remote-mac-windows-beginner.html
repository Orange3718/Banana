공유기 포트포워딩 없이 Tailscale로 대시보드·SSH·화면공유에 접근합니다.

보안 원칙
비밀번호·API 키·2FA 코드·SSH 개인키는 블로그, GitHub, 채팅에 입력하지 않습니다. 화면에는 가려진 예시만 사용합니다.

따라 하는 순서

Mac과 Windows에 Tailscale 설치
두 기기에서 같은 계정으로 로그인
Machines 화면에서 두 기기 확인
Mac의 Tailscale IP 또는 MagicDNS 이름 확인
필요한 서비스만 해당 주소와 포트로 접속
접근정책·기기 만료·업데이트 확인

완료 전에 확인하세요

  • 공유기에서 22·5900 포트를 공개하지 않았는가
  • 모르는 기기가 Tailnet에 들어와 있지 않은가
  • Mac 화면공유·SSH는 필요한 사용자에게만 허용했는가

막히면 이렇게 확인하세요

한 번에 여러 설정을 바꾸지 말고, 현재 단계의 앱이 실행 중인지와 오류 문구를 먼저 확인합니다. 오류 화면을 공유할 때는 이메일·IP·토큰·키를 가립니다.
