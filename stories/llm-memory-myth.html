8B 모델이면 8GB 메모리로 충분하다는 착각

파라미터 수와 양자화, KV cache는 서로 다른 메모리를 사용합니다.

먼저 결론
모델 이름의 8B를 보고 8GB RAM이면 된다고 생각하기 쉽습니다. 하지만 숫자는 파라미터 개수이고, 저장 비트와 실행 여유분, 컨텍스트가 실제 메모리를 결정합니다.

가격표에서 보이지 않던 것

8B 모델을 4비트로 저장하면 가중치 원시 계산은 약 4GB지만 런타임 오버헤드와 KV cache가 추가됩니다. 긴 문맥과 동시 사용자가 늘면 필요한 여유도 커집니다.

선택이 달라지는 순간

최소 실행과 편안한 사용을 구분하세요. 모델을 겨우 올리는 사양보다 원하는 컨텍스트와 속도로 유지되는 사양을 골라야 합니다.

결제 전에 세 가지만 확인하세요

  1. 원하는 컨텍스트 길이는 얼마인가
  2. GPU와 시스템 RAM을 어떻게 나눌 것인가
  3. 동시에 몇 명이 사용하는가
