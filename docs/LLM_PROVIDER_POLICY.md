# Atemoya LLM 제공자 정책

목표는 외부 API 비용을 최소화하면서 무료 Gemini 범위 안에서 필요한 품질만 보충하는 것이다.

## 라우팅

- **기본값: Ollama `qwen3.5:4b`** — 조사 정리, 제목·본문 초안, 분류, Telegram 요약.
- **Gemini 무료 보조** — 최신 자료를 근거로 한 일일 트렌드 합성, 하드웨어 설계처럼 로컬 4B가 품질을 못 맞추는 작업만 사용한다. 요청당 출력 상한을 낮게 유지하고 일 1회 수준으로 제한한다.
- **OpenAI** — 현재 저장소와 운영 워크플로에 호출 경로가 없다. 새로 추가하지 않는다.
- **Grok** — Grok 앱의 무료 사용은 수동 보조로만 사용한다. xAI API는 기본 Tier 0도 토큰 과금 API이며 무료 API라고 가정할 수 없으므로, 결제수단·크레딧이 확인되지 않은 상태에서는 n8n에 연결하지 않는다.
- **사람 승인 필요** — 게시, 결제, 계정 변경, 광고비 지출은 모델 제공자와 무관하게 자동 실행하지 않는다.

## 현재 확인 결과

`rg`로 저장소를 점검한 결과 OpenAI/GPT 호출은 없었다. Gemini 호출은 `AtemoyaDailyTrend01`, 하드웨어 실행 오케스트레이터, Telegram의 `/질문` 보조 경로에만 남아 있고, 커머스 스카우트와 로컬 병렬 레인은 Ollama를 사용한다.

무료 한도는 Google 계정·지역·시점에 따라 달라지므로 숫자를 고정하지 않는다. n8n 실행 기록과 Gemini 응답 오류를 매일 확인하고, 무료 한도 오류가 나면 자동으로 로컬 모델 결과를 사용한다.

xAI 공식 문서상 API 호출은 모델별 토큰 가격이 있고, 한도 tier는 누적 지출 기준이다. 따라서 “Grok 무료 앱”과 “Grok API 무료”를 같은 것으로 취급하지 않는다.
