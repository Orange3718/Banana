## 실제 구조

| 시트 | 원본 열 순서 | 실적 행 |
|---|---|---|
| clicks | 날짜 / 채널 ID / 링크 타입 / 링크 ID / 링크 타입 | 0 |
| orders | 날짜 / 채널 ID / 상품 ID / 상품명 / 판매 수량 / 매출 액 / 수익 / 취소 수량 / 취소 액 / 취소 수익 | 0 |

숫자 0인 데이터 행이 아니라 헤더만 있는 파일이다. 따라서 내부 재무 값은 확인되지 않은 null이며, 빈 파일만으로 확정 수수료 0·입금 0을 전기하지 않는다. 사용자가 포털에서 확인한 0원과 모순된다는 뜻도 아니다. 자료 형식이 입증하는 범위가 다르다.

clicks에는 동일한 ‘링크 타입’ 헤더가 두 번 나온다. 열 이름을 key로 바로 변환하면 하나가 덮어써질 수 있다. 중복을 보존해 duplicate_headers로 표시하며, 임의로 마지막 열을 ‘클릭 수’라고 바꾸지 않는다.
