현재 시스템과 네이버 공식 도움말 표면에서는 지원되는 무인 글쓰기 API 경로를 확인하지 못했다. 따라서 이번 파일럿은 브라우저 보조 게시이며, 백그라운드 자동 게시로 간주하지 않는다. 비밀번호·OTP·QR 값은 저장소나 대화에 저장하지 않는다.
