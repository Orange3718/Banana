## 저토큰 후속 운영

정상 게시에서는 다음 다섯 단계만 수행한다.

1. 로컬 manifest와 결정론적 검사로 제목·본문·고지·링크·태그를 한 번에 확정한다.
2. 유지된 네이버 세션에서 제목 1회, 본문 1회, 태그 묶음 1회만 입력한다.
3. 전체공개·검색허용·주제만 확인하고 최종 발행 실행시점 확인을 1회 받는다.
4. 반환 URL의 `PostView`를 로컬 HTTP 검사로 검증하고 전체 접근성 트리는 읽지 않는다.
5. 실패·화면 변경·2FA가 있을 때만 스크린샷이나 전체 UI 트리를 연다. 정상 건에는 병렬 에이전트 리뷰를 사용하지 않는다.

이 경로는 모델 호출 없이 게시 원고를 재사용하고, 화면 토큰을 정상 건당 최소화한다.
