# 16. 쿠팡 10개 카테고리 게시 계획

상태: 링크 생성 대기 — 쿠팡 파트너스 세션 재로그인 필요

## 게시 대상 카테고리

1. 뷰티·피부관리
2. 주방·식품보관
3. 청소·생활가전
4. 건강·운동
5. 반려동물
6. 육아·출산
7. 여행·휴대용품
8. 사무·재택근무
9. 계절·냉난방
10. 모바일·전자기기

각 글은 서로 다른 상품 1개를 대상으로 하며, 상품 검증 후에만 다음 값을 확정한다.

- 쿠팡 공식 단축 제휴 링크
- 내부 `link_key`
- 실제 상품명·상품 ID
- 공개 페이지 경로
- 쿠팡 고지 문구와 `rel="sponsored nofollow"`

## 게시 게이트

- 파트너스 로그인 세션 확인
- 상품 페이지 HTTP/화면 확인
- 파트너스 도구가 반환한 링크를 그대로 기록
- 링크 목적지와 고지 문구 정적 검사
- 공개 빌드·배포 후 10개 URL HTTP 200 및 링크 포함 확인

현재 Chrome 쿠팡 로그인 화면과 상품 페이지 403을 확인했다. 세션이 없는 상태에서 링크 문자열을 추측하거나 기존 상품 링크를 다른 상품에 재사용하지 않는다.
