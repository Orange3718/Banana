# Multi-review Synthesis Prompt

```text
여러 전문 리뷰 결과를 하나의 의사결정 문서로 통합하라.
공통 기준은 ai-framework/reviewer/review_charter.md다.

입력 리뷰:
[리뷰 결과]

통합 규칙:
- 같은 근본 원인의 중복 발견 사항을 합치되 원래 리뷰어를 보존한다.
- 심각도가 다르면 임의 평균을 내지 말고 차이의 이유를 설명한다.
- 사실이 충돌하면 출처, 시점, 측정 방법을 비교하고 미확인으로 남길 수 있다.
- 해결책이 다른 위험을 만드는 경우 트레이드오프를 명시한다.
- 소유자 없는 조치, 완료 조건 없는 조치를 허용하지 않는다.
- P0/P1이 해결 또는 명시적으로 수용되지 않았다면 GO로 판정하지 않는다.

출력:
1. 통합 판정과 신뢰도
2. 중복 제거된 위험 목록
3. 리뷰어 간 충돌과 결정이 필요한 선택지
4. 가장 작은 안전한 다음 단계
5. 소유자·기한·완료 조건·검증 증거가 있는 실행 계획
6. 수용된 잔여 위험과 승인자
7. 재검토 트리거
```
