# Post-Launch Review Checklist

## 결과 확인

- [ ] 출시 버전, 시각, 대상 범위가 기록되어 있다.
- [ ] 핵심 여정과 공개 결과물을 실제 사용자 경로에서 확인했다.
- [ ] 성공 지표를 사전 기준값·목표·기간과 비교했다.
- [ ] 측정 누락과 실제 성과 부재를 구분했다.
- [ ] 비용과 공헌이익을 예상치와 비교했다.

## 품질과 위험

- [ ] 오류, 지연, 지원 문의, 이탈을 세그먼트별로 확인했다.
- [ ] 보안·개인정보·권한 이상 징후를 검토했다.
- [ ] AI 품질, 거부, 근거 오류, 승인 우회를 표본 검사했다.
- [ ] 중복 실행, 큐 정체, 재시도 폭주, 알림 누락이 없다.
- [ ] 새 위험과 예상 밖 사용 방식을 위험 등록부에 추가했다.

## 학습과 결정

- [ ] 성공과 실패의 인과 설명에 증거 수준을 표시했다.
- [ ] 반증된 가정과 유지할 가정을 구분했다.
- [ ] 계속 / 확대 / 수정 / 롤백 / 중단 중 하나를 결정했다.
- [ ] 확대 전 용량·비용·운영·지원 한도를 재검토했다.
- [ ] 사용자 피드백이 구체적인 제품·운영 조치로 연결되었다.

## 후속 조치

- [ ] P0/P1은 즉시 소유자와 완료 조건을 부여했다.
- [ ] P2/P3은 우선순위와 비용을 반영해 백로그화했다.
- [ ] 임시 feature flag, 권한, 예외, 데이터가 정리되었다.
- [ ] 문서, 런북, 평가 세트, 체크리스트를 실제 학습으로 갱신했다.
- [ ] 다음 측정·리뷰 시점과 결정권자를 기록했다.
