먼저 결론
LED 마스크는 색상 수나 할인율만으로 비교하기 어렵습니다. 실제 구매 전에는 사용시간, 눈 보호, 충전 방식, A/S와 반품 조건을 확인하세요.

구매 전 체크리스트

  1. 사용시간: 1회 권장 시간이 명확하고 타이머가 있는지 확인
  2. 눈 보호: 보호안경 필요 여부와 제조사의 주의사항 확인
  3. 광원 표기: 색상 개수보다 파장·출력·측정 조건이 공개되어 있는지 확인
  4. 착용감: 무게, 얼굴 고정 방식, 유선·무선 여부 비교
  5. A/S와 반품: 국내 A/S 기간과 단순 변심 반품 조건 확인
  6. 표현의 범위: 질환 치료·개선 효과를 단정하는 광고는 근거를 다시 확인
